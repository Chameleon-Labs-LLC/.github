# Contributing to Chameleon Labs projects

Thanks for taking a look. Bug reports, ideas and pull requests are all welcome, whether it's your first contribution or your fiftieth. This guide applies to every repository in the organization that doesn't have its own `CONTRIBUTING.md`.

We don't take money donations. Code, bug reports and good ideas are the best gifts.

## Questions and ideas

The quickest place to talk something through is the [Chameleon Labs Discord](https://discord.gg/chameleonlabs). Once an idea is concrete, open an issue in the repository it belongs to.

## Reporting a bug

Search the repository's existing issues first. If it's new, open an issue with:

- what you did, step by step
- what you expected, and what happened instead (paste the error text or log output)
- your operating system and the version or commit you're running

Security problems are different. Please report those privately, as described in our [security policy](SECURITY.md).

## Pull requests

1. Fork the repository and create a branch from the default branch.
2. Keep each pull request to one fix or one feature.
3. Match the existing code style, and run any tests the README mentions before you push.
4. Say what changed and why in the description.

For anything bigger than a small fix, open an issue or ask on Discord first. Nobody wants you to spend a weekend on something that needed a five-minute conversation.

Looking for somewhere to start? Try an issue labelled [`good first issue`](https://github.com/search?q=org%3AChameleon-Labs-LLC+label%3A%22good+first+issue%22+state%3Aopen&type=issues).

## Plugins

To add or update a Claude Code plugin in our marketplace, open a pull request against [Chameleon-Labs-LLC/plugins](https://github.com/Chameleon-Labs-LLC/plugins) and follow its README.

## License

By contributing, you agree that your contribution is licensed under the same license as the repository you're contributing to (see its `LICENSE` file). If a repository has no license yet, please open an issue and ask before you contribute.

Our setup guide and the projects we share are at <https://chameleonlabs.ai/open-source>.
