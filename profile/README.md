# Chameleon Labs, LLC

> **Never blend, always adapt.**

We build adaptive software that evolves with your business needs.

## What we build

- **[QuickStock](https://quickstock.chameleonlabs.ai)** — Mobile-first inventory for businesses, collectors, and home use. QR scanning, photo capture, offline support, and sales tracking.
- **[RealtyShield](https://realtyshield.chameleonlabs.ai)** — AI-assisted real estate compliance review for MO, IL, and KS, with privacy-first document handling.
- **[HealthCheck](https://healthcheck.chameleonlabs.ai)** — Free health assessments with optional AI-powered analysis and history tracking.
- **[Maestro AI](https://chameleonlabs.ai/apps/maestro)** — One subscription for top AI models, with conversation memory and model switching.

## Open-source work

A few of our public repositories:

- **[MultiTeamAgenticCoding](https://github.com/Chameleon-Labs-LLC/MultiTeamAgenticCoding)** — Agent Pi system for multiple teams of multiple agents.
- **[ClaudeCodeDashboard](https://github.com/Chameleon-Labs-LLC/ClaudeCodeDashboard)** — Local Claude Code dashboard for searching sessions, viewing memory, and more.
- **[Heimdallr](https://github.com/Chameleon-Labs-LLC/Heimdallr)** — Monitoring service for AWS Amplify and EC2, adaptable to other services.
