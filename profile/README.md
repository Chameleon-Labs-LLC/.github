# Chameleon Labs, LLC

> **Never blend, always adapt.**

We build adaptive software that evolves with your business needs.

## What we build

- **[QuickStock](https://quickstock.chameleonlabs.ai)** — Mobile-first inventory for businesses, collectors, and home use. QR scanning, photo capture, offline support, and sales tracking.
- **[RealtyShield](https://realtyshield.chameleonlabs.ai)** — AI-assisted real estate compliance review for MO, IL, and KS, with privacy-first document handling.
- **[HealthCheck](https://healthcheck.chameleonlabs.ai)** — Free health assessments with optional AI-powered analysis and history tracking.
- **[Maestro AI](https://chameleonlabs.ai/apps/maestro)** — One subscription for top AI models, with conversation memory and model switching.

## Open source

### Chameleon Labs projects

- **[model-registry-client](https://github.com/Chameleon-Labs-LLC/model-registry-client)** — Resolve current LLM model IDs (Anthropic / OpenAI / Gemini) at runtime from a public registry. Zero-dependency Python + TypeScript clients.
- **[humanizer](https://github.com/Chameleon-Labs-LLC/humanizer)** — Managed agent that strips AI fingerprints from writing and replaces them with a per-user voice profile.
- **[ClaudeCodeDashboard](https://github.com/Chameleon-Labs-LLC/ClaudeCodeDashboard)** — Local Claude Code dashboard for searching sessions, viewing memory, and more.
- **[agent-spawner](https://github.com/Chameleon-Labs-LLC/agent-spawner)** — Scaffold, package, and deploy Claude agents — channel adapters, HMAC bridges, and one-command SSH deploy.
- **[agent-deploy](https://github.com/Chameleon-Labs-LLC/agent-deploy)** — Secure EC2 setup guide and ops toolkit for running AI coding agents (Claude Code, Codex, Gemini, pi) on a dedicated instance.
- **[MultiTeamAgenticCoding](https://github.com/Chameleon-Labs-LLC/MultiTeamAgenticCoding)** — Agent Pi system for multiple teams of multiple agents.
- **[AWS-Admin](https://github.com/Chameleon-Labs-LLC/AWS-Admin)** — Secure local CLI for AWS admin tasks — Amplify env vars and curated DB queries with no secrets ever entering a prompt or transcript.
- **[license-validator](https://github.com/Chameleon-Labs-LLC/license-validator)** — Shared license verification for Chameleon Labs commercial plugins. MIT-licensed, bundles only public keys.
- **[plugins](https://github.com/Chameleon-Labs-LLC/plugins)** — Claude Code plugin marketplace for Chameleon Labs.
- **[okf-tools](https://github.com/Chameleon-Labs-LLC/okf-tools)** — Zero-dependency toolkit library powering our autonomous agents.
- **[Heimdallr](https://github.com/Chameleon-Labs-LLC/Heimdallr)** — Monitoring service for AWS Amplify and EC2, adaptable to other services.
